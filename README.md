AI-powered personalized travel guide for Kazakhstan.

## About the Project

QazaqGuide AI is a web application designed to help users discover Kazakhstan and plan personalized trips.

The system analyzes user preferences, budget, trip duration, and interests to recommend suitable tourist destinations and generate personalized travel itineraries.

The project is being developed as a bachelor's thesis in the field of Artificial Intelligence Technologies.

## Main Features

- Personalized tourist recommendations
- AI-powered travel assistant
- Personalized itinerary generation
- Tourist destination search
- Interactive map
- Budget-aware trip planning
- AI-based travel recommendations

## Planned AI Technologies
